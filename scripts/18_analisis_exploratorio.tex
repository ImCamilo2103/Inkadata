\section{Introducción}
Este reporte presenta el análisis de medidas de tendencia central y dispersión para los datos de las empresas y establecimientos, cubriendo los años 2016, 2019 y 2022. 
Se incluyen medias, medianas, desviaciones estándar, cuartiles, asimetría y curtosis para cada variable analizada.

\section{Metodología}
\begin{itemize}
    \item Los datos fueron obtenidos de las vistas \texttt{eam2016}, \texttt{eam2019} y \texttt{eam2022} en la base de datos PostgreSQL.
    \item El procesamiento estadístico se realizó en \texttt{R}, utilizando los paquetes \texttt{dplyr}, \texttt{e1071} y \texttt{ggplot2}.
    \item Se calcularon medidas descriptivas clásicas: media, mediana, desviación estándar, varianza, coeficiente de variación, asimetría y curtosis.
    \item Los resultados fueron exportados a tablas y gráficas para facilitar su interpretación.
\end{itemize}

\section{Conclusiones}

\begin{itemize}
    \item Las variables muestran una tendencia estable en los tres periodos, aunque con diferencias notables en dispersión.
    \item El coeficiente de variación indica que algunas variables tienen una alta heterogeneidad, lo que puede deberse a la estructura productiva de las empresas.
    \item La asimetría positiva sugiere concentración de empresas con valores bajos en ciertas variables, mientras unas pocas tienen valores muy altos.
    \item La curtosis alta en algunas variables sugiere colas pesadas, indicando posibles outliers o concentración de valores extremos.
\end{itemize}
